# Orbit — World Clock

An animated, responsive world clock built with vanilla HTML, CSS, and JavaScript. Orbit uses the browser's native `Intl.DateTimeFormat` API for accurate time-zone conversion, so there are no API keys or build steps.

## Features

- Live clocks with daylight/nighttime status and UTC offsets
- Add and remove cities with local-storage persistence
- Animated aurora, stars, glow, and grid effects
- Responsive glassmorphism interface
- Zero dependencies — open `index.html` directly or deploy to GitHub Pages

## Run locally

Open `index.html` in a browser. For the best experience, use a simple static server such as `python3 -m http.server`.
